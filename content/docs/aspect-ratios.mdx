A page renders at any `W:H` ratio of whole numbers. Five ratios are common: `16:9`, `9:16`, `1:1`, `4:5` and `4:3`. `1200:630` and `2:1` work too. You write the layout once in CSS.

## What the renderer gives you

Before your scripts run, the renderer sets:

- `<html data-aspect="16:9">` (or the ratio being rendered)
- `--vw` and `--vh` on `:root`, as pixel lengths
- `window.vawe`, with `aspect`, `width`, `height` and `fps`

Use them in CSS:

```css
h1 { font-size: calc(var(--vh) * 0.11); }
[data-aspect="9:16"] h1 { left: 8%; top: 30%; }
```

`--vh` holds a unit (for example `1920px`). Write `calc(var(--vh) * 0.11)`, never `* 0.11px`.

Do not crop. Do not lay out in fixed pixels for 16:9.

## Render a ratio

```bash
bin/vawe dev  films/<name>/page.html --aspect 9:16    # one draft
bin/vawe ship films/<name>/page.html --aspect all     # one file per ratio
```

Without `--aspect`, the render uses the `aspect` meta of the page, else `16:9`. Draft `--aspect 9:16` once before the final.

A ratio that is not in the table gets a size that fits 1920 px on its long edge. The output name gets the ratio (`-2x1`), so two ratios do not overwrite each other. `bin/vawe still <page> --size 1200x630` writes a PNG of that size when the ratio matches the aspect.

Each ratio is its own reproducible render. See [Determinism](/docs/determinism).

## Sizes

| Ratio | Full size |
|---|---|
| `16:9` | 1920 × 1080 |
| `9:16` | 1080 × 1920 |
| `1:1` | 1080 × 1080 |
| `4:5` | 1080 × 1350 |
| `4:3` | 1440 × 1080 |
| any other `W:H` | 1920 px on the long edge |

`bin/vawe ship <page> --aspect all` writes one file per ratio of the table. A draft is half this size.
