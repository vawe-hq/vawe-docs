The <Term id="aspect">aspect</Term> is the width-to-height ratio of a film. A page renders at any ratio of two whole numbers, such as `16:9`, `9:16`, `1:1`, `4:5`, `4:3`, `2:1` or `1200:630`. You write the layout once in CSS, and the renderer gives it a different size.

## Why it exists

One film often goes to several places: a wide player, a phone feed, a square post. A film that crops one canvas to fit another loses the edges of its layout. A film that lays out again for each canvas keeps every word and every mark in the frame. So the renderer never crops. It gives the page the size of the aspect, and the page lays itself out.

The renderer picks the aspect in this order. The first one that exists wins:

1. `--aspect W:H` on a render verb.
2. `<meta name="aspect">` in the page.
3. `16:9`.

It then sets three things before your scripts run:

- `<html data-aspect="W:H">`, for example `data-aspect="9:16"`.
- `--vw` and `--vh` on `:root`, the width and height of the layout viewport as pixel lengths.
- `window.vawe.aspect`, `window.vawe.width` and `window.vawe.height`.

The page sees an `--aspect` flag in the same way as the meta. A draft captures at half size, but the layout viewport has the full size, so a draft lays out exactly like a final.

## Write the layout

Use `--vh` and `--vw` for sizes and `[data-aspect]` selectors for changes between aspects.

```css
h1 { font-size: calc(var(--vh) * 0.11); }
[data-aspect="9:16"] h1 { left: 8%; top: 30%; }
```

`--vh` holds a unit (for example `1920px`). Write `calc(var(--vh) * 0.11)`, never `* 0.11px`.

<Callout kind="rule">
Never crop, and never lay out in fixed pixels for 16:9. Draft `--aspect 9:16` once before the final.
</Callout>

## Render an aspect

```bash
bin/vawe dev  films/<name>/page.html --aspect 9:16    # one draft
bin/vawe ship films/<name>/page.html --aspect all     # one file for each of the five common aspects
bin/vawe dev  films/<name>/page.html --aspect 2:1     # any whole W:H
```

`--aspect all` renders the five aspects in the table below, one file each. Any other ratio gets its own flag value. The default output name gets the aspect (`-2x1`), so two aspects do not overwrite each other.

`bin/vawe still <page> --size 1200x630` writes a PNG of that size. The size must have the ratio of the aspect, so pass `--aspect 1200:630` with it.

## Sizes

| aspect | final size |
|---|---|
| `16:9` | 1920 x 1080 |
| `9:16` | 1080 x 1920 |
| `1:1` | 1080 x 1080 |
| `4:5` | 1080 x 1350 |
| `4:3` | 1440 x 1080 |
| any other `W:H` | 1920 px on the long edge |

Any ratio with equal sides, such as `3:3`, gives 1080 x 1080. A draft is half the size of the table. The renderer rounds each side of the output to an even number, because the encoder refuses an odd side.

## Limits

- A value that is not two whole numbers, such as `16/9` or `0:1`, stops the render with an error that says `is not a W:H ratio of whole numbers`.
- Two aspects of one page are two separate renders. Each one is <Term id="determinism">deterministic</Term> by itself. See [Determinism](/docs/determinism).
