One command runs everything: `bin/vawe`. `bin/vawe --help` lists the 10 verbs. `bin/vawe <verb> --help` lists the flags. A wrong flag exits 2 and prints the valid ones.

The verbs, the loop. There are 10:

| Verb | What it does |
|---|---|
| `new` | start a film: `films/<name>/page.html` and `brief.md`. It asks for the details that the request leaves open. `--defaults` guesses them |
| `see` | read a film, page or reference as numbers: shots, motion, light, type, sound. `--vs <ref>` adds deltas and advice. `--spec` measures a reference into `SPEC.md` and `spec.json`. `--plan` prints the worlds, the rhythm and the cues of a page as text |
| `frame` | a picture of a film. `--at <s>` one frame, `--at s,s,s` a sheet, `--world all` one still per world, `--cuts`, `--moment <s>` (with `--onion` or `--velocity`), `--box` or `--auto` for a region, `--looks`, `--board`, `--directions`, `--vs <mp4>` |
| `dev` | draft render: half size, 30 fps, audio mixed (a `--from/--to` window is silent, and so is `--silent`), plus a key-frame sheet PNG |
| `ship` | final render: 60 fps, motion blur, audio mixed, then a final check and a fresh judge. Runs in the background. It refuses until a fresh review and your two OKs exist |
| `wait` | wait for a running render or critique and print its result |
| `critique` | phone sheet, strip, loop seam, measured deltas and `page-check`. `--fresh` starts a separate read-only critic |
| `refs` | list the reference films, print the settled frame of every shot, add a film |
| `check` | run one gate or report by name (`review`, `coverage` and `links` among them). Bare `check` lists them |
| `sound` | synth voices, the beat grid and hits of a track, the cues of a page. `--sfx` imports an effect, `--lab` listens |

The old picture verbs `still`, `frames`, `sheet`, `strip`, `zoom` and `storyboard` still work as aliases. Each prints the `frame` command it became. `storyboard --text` became `see --plan`.

| Old verb | Now |
|---|---|
| `animatic` | `dev --animatic`: the key frame of each world, held for its planned span, hard cuts, silent |
| `studio` | `dev --studio`: a live scrubbable preview that edits the page literals in place |
| `shot` | `new --from-url <url>`: screenshots of a site route, a url or an html page at several widths |
| `fonts`, `palette` | retired. `new` writes the free faces and the palette seed into `brief.md` |

## Developer tool: vawe-dev

`bin/vawe-dev` holds the tools for work on vawe itself. A film maker does not need it. `bin/vawe-dev <verb> --help` lists the flags.

| Verb | What it does |
|---|---|
| `land` | put the current branch on main: fetch, rebase, run the tests, push |
| `claim` | declare or release the scope a worktree works in |
| `e2e` | page tests plus a parallel half-size draft of every film |
| `test` | run every `tests/**/*.test.mjs` |
| `runs` | where a film's time went and what failed. `--all` gives one row per film |
| `moves` | render the stale clips of the moves library |
| `doctor` | check Node, ffmpeg, Chrome and the other tools. It prints the install line for each missing one |
| `check` | run one repo gate or report by name. The film gates stay in `bin/vawe check` |
| `judge` | prepare key frames and the rubric for a fresh session to score. `--fresh` scores now |
| `approve` | record the owner OK on the full draft |
| `worktrees`, `bots` | list the agent worktrees, read the site bot log |

The old forms `bin/vawe land`, `claim`, `e2e`, `test`, `runs`, `moves`, `doctor`, `judge` and `approve` still run as aliases. Each prints the `vawe-dev` command it became.

You do not run `approve` in a film session. The person gives the OKs by typing `/vawe-approve` in the chat. See [Ship](/docs/ship).

## The flags you use most

```bash
bin/vawe new my-film --from prompts/story-explainer.md --length 30 --aspect 16:9 --title "..."
bin/vawe dev films/my-film/page.html --from 2 --to 6 --aspect 9:16 --silent
bin/vawe ship films/my-film/page.html --aspect all
bin/vawe wait films/my-film/page.html
bin/vawe frame films/my-film/page.html --at 2.5,3.1,4
bin/vawe dev films/my-film/page.html --studio --port 8800
```

- `new --ref <mp4>` recreates a reference. It writes `films/recreations/<name>` with `SPEC.md`.
- `new --from-url <url>` captures a website. See [Render flags](/docs/render-flags).
- `new --answers <file>` and `new --detail key=value` give the details. `--questions-json` prints the open details as `AskUserQuestion` calls and writes nothing.
- `--aspect <W:H>` takes any ratio of whole numbers. `16:9`, `9:16`, `1:1`, `4:5` and `4:3` are the common ones. `1200:630` and `2:1` work too. `dev`, `ship` and `frame --at` take it.
- `--param key=value` passes an option to the page, which reads it with `new URLSearchParams(location.search)`. For example, `--param look=riso`. It is repeatable. `dev`, `ship` and `frame --at` take it. The output name gets the value (`-look-riso`).
- `frame --at <s> --size WxH` sets the PNG size, for example `1200x630`. Its ratio must match the aspect of the page.
- `dev --silent` leaves the audio out of the draft.
- `dev --out <path>` sets the output file. The default is `out/<name>-draft.mp4`.
- `ship --out <path>` sets the output file. The default is `out/<name>.mp4`. It does not combine with `--aspect all`.
- `ship --wait` blocks until the render ends. `wait <page>` waits for a background render or critique and prints the result. One call returns after about 3.5 minutes with a progress line each minute. If it says `STILL RUNNING`, run it again.
- `critique --ref <mp4>` measures against a reference. With `--final`, a pass unlocks `ship`.
- `critique --fresh` starts a separate read-only critic and writes `out/<film>.critique-<n>.md`. The ship gate accepts it as the fresh review.
- `dev --whole` renders the whole film. With an empty plan, `dev` renders a short window around the big moment.
- `vawe-dev judge --fresh` scores now with a separate headless session. It advises and never blocks.

## The loop, end to end

```bash
bin/vawe new my-film --from prompts/<template>.md   # brief and starter page
bin/vawe dev films/my-film/page.html                # draft
bin/vawe critique films/my-film/page.html --fresh   # a separate critic
bin/vawe dev films/my-film/page.html --from 2 --to 4  # fix only the named seconds
bin/vawe ship films/my-film/page.html               # final, after the person typed /vawe-approve twice
```

See [Checks](/docs/quality-gates) for `check`, and [Critique and fix](/docs/critique) for the views.
