By the end of this page you have a <Term id="draft">draft</Term> of a short <Term id="film">film</Term> in `out/`. You need a terminal and Node 22 or newer. [Install](/docs/install) lists every requirement.

<Steps>
<Step>

### Install vawe

Clone the repository, go into its folder, install the packages, and install Chrome for the renderer.

```bash
git clone https://github.com/vawe-hq/vawe.git && cd vawe
npm install
npx puppeteer browsers install chrome
```

The install runs `doctor` at the end.

</Step>
<Step>

### Check the tools

```bash
bin/vawe doctor
```

When all is well, you see `ok, 7 checks` and the name of your system. If a tool is missing, `doctor` prints `MISSING` and a `fix:` line with the install command. Read [Install](/docs/install).

</Step>
<Step>

### Start a film

```bash
bin/vawe new hello --request "a 5 s sting for a coffee brand" --defaults --length 5
```

`new` writes `films/hello/page.html`, a valid starter <Term id="page">page</Term>, and `films/hello/brief.md`. The <Term id="brief">brief</Term> holds the facts of the film.

Without `--defaults`, `new` asks for the details that the request leaves open: subject, message, what to show, format, assets and ending. With `--defaults`, it guesses each open detail and marks the guess `(guess: change me)`. Change each guess before you go on.

</Step>
<Step>

### Render a draft

```bash
bin/vawe dev films/hello/page.html
```

The draft is half size at 30 fps, with the `<audio>` tags mixed. Add `--silent` for a picture-only draft. To render only the seconds you work on, add `--from 2 --to 4`. A range has no sound.

</Step>
<Step>

### Find the output

The draft is `out/hello-draft.mp4`, with a sheet of key frames next to it. A range gives `out/hello-draft-<from>-<to>.mp4`. Open the mp4 in any player. To look at the whole draft, run `bin/vawe sheet out/hello-draft.mp4`.

Every verb ends with a line such as `vawe: dev ok in 12s`. Each verb also adds a line to `out/hello.runs.jsonl`. Read [Use with an agent](/docs/agents#the-run-log).

</Step>

</Steps>

<Callout kind="note">
`dev` runs a stills judge on the three directions of the film, once for each change of `directions.html` or of their brief lines. It takes about 25 s. Add `--no-judge` to skip it.
</Callout>

## If it fails

| What you see | Why | What to do |
|---|---|---|
| `MISSING ...` from `doctor` | A required tool is not installed. | Run the `fix:` line, then run `bin/vawe doctor` again. |
| `unknown verb` | The verb name has a typo, or the checkout is old. | Run `bin/vawe --help` and compare the names. |
| `new` prints questions | The request leaves a required detail open. | Answer with `--answers <file>` or `--detail key=value`, or add `--defaults`. |
