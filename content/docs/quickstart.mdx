## Setup

Run `npm install`, then `bin/vawe doctor`. It checks Node, ffmpeg, Chrome and the other tools. For each tool that is missing, it prints the install line.

## Start a film

```bash
bin/vawe new hello --defaults --length 5 --title "hello, film"
```

Without `--defaults`, `new` asks for the details it needs and writes nothing. It asks for up to eight: subject, message, what to show, look, format, family, assets and ending. With `--defaults`, it guesses each open detail and marks the guess `(guess: change me)`.

The command writes `films/hello/page.html` (a valid starter), `brief.md` and `directions.html`. Flags such as `--length`, `--aspect` and `--title` set the starter values. Run `bin/vawe new --help` for the list.

The starter is a short brand sting with three worlds. This is its outline:

```html
<!doctype html>
<html data-aspect="16:9">
<head>
<meta charset="utf-8">
<meta name="duration" content="5">
<meta name="aspect" content="16:9">
<meta name="message" content="one thing to remember">
<meta name="spectacle" content="1.8">
<meta name="signature" content="band=; ease=; stagger=; seam=; palette=; thread=">
<title>hello, film</title>
<style>
  @font-face { font-family: "Hanken Grotesk"; src: url("assets/HankenGrotesk.woff2") format("woff2"); font-weight: 100 900; }
  :root { --ground: #8c8c8c; --ink: #1c1c1c; --beat-1: 0s; --beat-2: 1.5s; --beat-3: 3.5s; }
  /* styles for the worlds, the ground, the mark, the word and the line */
</style>
<script type="module">
import { enter, EASE } from '../../core/motion/presets.js';
/* each world cuts in at its beat, the mark enters, and the word opens at the spectacle */
</script>
</head>
<body>
<div class="world" data-world="s1"><div class="ground" aria-hidden="true"><i></i><i></i><i></i></div></div>
<div class="world" data-world="s2">...</div>
<div class="world" data-world="s3">...</div>
<div class="lockup">
  <div class="row">
    <svg class="mark" viewBox="0 0 100 100" role="img" aria-label="mark">...</svg>
    <h1 class="word">hello, film</h1>
  </div>
  <p class="line">why it matters</p>
</div>
</body>
</html>
```

Each beat is one element with `data-world`. Replace the stand-in mark, colours and font with your own. Keep the beats. The page has no `<audio>` tag yet. Add the cues later (see [Audio](/docs/audio)).

## The loop

```bash
bin/vawe dev      films/hello/page.html                  # draft: half size, 30 fps, audio mixed
bin/vawe dev      films/hello/page.html --from 2 --to 4  # only the seconds you work on (silent)
bin/vawe critique films/hello/page.html                  # in a fresh session
bin/vawe approve  films/hello/page.html                  # you, after you watch the whole draft
bin/vawe ship     films/hello/page.html                  # final: 60 fps, blur, audio
```

Draft the hardest two to four seconds first. Give the draft to a session that did not write the page. It names the shot, the frame and the fix. Fix the worst items, render only those seconds again, and critique again.

`bin/vawe ship` refuses until a fresh session has reviewed the page and you have run `bin/vawe approve` on the whole draft. It runs in the background. Run `bin/vawe ship --status --wait` to wait for the result. It waits up to 3.5 minutes. If the render is not done, run it again.

<Callout title="No em dashes on screen">
On-screen copy cannot contain an em dash. The validator rejects it. Use a comma, a period or a middot.
</Callout>
