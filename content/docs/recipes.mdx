Each recipe has a beat table: the time, the move, what carries into the next beat, and the sound cue. One row in each table reads `invent: the film's own moment`. Do not copy it. Design that beat from your own brief. After the table come the reason the chain holds and the traps at each seam.

## Why a chain holds

The recipes share three habits.

- One element carries through the film. A name, a dot or a cursor moves from beat to beat.
- Each seam changes axis or direction. Scale out, then x, then a scale land, then y.
- The slowest beat is at least 3 times the fastest.

## Use one

1. Copy the moves from `prompts/moves/`. Each move has a snippet and a clip.
2. A snippet's delays start at 0. Add the beat start to each one.
3. Measure every rectangle with the layout at rest, before any `vawe.onFrame` hook sets a transform.
4. Add the sound cue named in the table as `<audio data-synth="<voice>" data-at="<s>">`, with no `data-gain`.

Read the traps before you copy a chain. For example, in the brand sting the first shot needs its own ground, or the second shot shows through before the block covers it.

See [Motion](/docs/motion) for the rules the chains follow.
