This page lists the flags that change a render. The list comes from `bin/vawe <verb> --help` for `dev`, `frame` and `ship`. A wrong flag exits 2 and prints the valid ones. For the other verbs, see [CLI](/docs/cli).

Four flags work the same way in more than one verb:

- `--aspect <W:H>` sets the <Term id="aspect">aspect</Term>. It overrides the page `aspect` meta. The default output name gets it (`-2x1`), so two aspects do not overwrite each other. See [Aspect ratios](/docs/aspect-ratios).
- `--param key=value` passes an option to the page. The page reads it with `new URLSearchParams(location.search)`. The flag is repeatable. It is part of the <Term id="render-key">render key</Term>, and the default output name gets it (`-look-riso`). A repeated key exits with an error, because a page reads one value per key (`harness/lib/page-params.mjs`). See <Term id="param">param</Term>.
- `--from <s>` and `--to <s>` render a window of the film.
- `--out <path>` sets the output file or folder.

## dev

The <Term id="draft">draft</Term>: half size, 30 fps. It also writes a key-frame sheet PNG next to the mp4. See [Draft](/docs/draft). While the "Ideas" or the "Board" of the brief is empty and no full draft exists, `dev` renders a small 2 s window around the big moment to `out/<name>-plan-window.mp4`. Use `--whole` to render the full film.

| Flag | What it does | Default | Example |
|---|---|---|---|
| `--from <s>` | Start second. A window is silent | none | `--from 2` |
| `--to <s>` | End second | none | `--to 6` |
| `--aspect <W:H>` | Set the aspect | the page meta, else 16:9 | `--aspect 9:16` |
| `--param <key=value>` | Pass an option to the page | none | `--param look=riso` |
| `--silent` | Leave the audio tags out of the mix. Faster | off | `--silent` |
| `--small` | Encode about 5 times smaller, for a file to post such as an `og:video` loop (x264 preset fast, CRF 24) | off | `--small` |
| `--lock-length` | Write the found length of a `duration="auto"` page into its meta | off | `--lock-length` |
| `--out <path>` | Output file | `out/<name>-draft.mp4`, or `out/<name>-draft-<from>-<to>.mp4` for a window | `--out out/a.mp4` |
| `--fast` | Run only the fast checks | off | `--fast` |
| `--full` | Also run the ship-tier checks: per-frame box motion lint, object tracks, loudness and peak | off | `--full` |
| `--taste` | Also print the taste lines. They are always in `out/<name>.dev.md` | off | `--taste` |
| `--whole` | Render the whole film. Without it, an empty plan gives a 2 s window around the big moment | off | `--whole` |
| `--no-judge` | Skip the stills judge that `dev` runs on the three directions, once per change of `directions.html` or their brief lines (about 25 s) | off | `--no-judge` |

```bash
bin/vawe dev films/my-film/page.html --from 2 --to 6
```

## frame

A picture of a film. The input is a page, an mp4, a reference id or a folder. One mode flag picks what `frame` draws. See [Key frames](/docs/key-frames) and [Critique and fix](/docs/critique).

| Mode | What it draws | Example |
|---|---|---|
| `--at <s>` | One exact full-size PNG. A second past the last frame moves to the last frame, and the output says so | `--at 4.2` |
| `--at <s,s,s>` | A labelled sheet. `--at cuts`, or no `--at`, picks the cuts | `--at 0.5,1.2,3` |
| `--world <id\|all>` | A still of the key state of each world, and with `all` a contact sheet | `--world s3,s5` |
| `--cuts` | One grid of frames per cut | `--cuts` |
| `--moment <s>` | The frames through that second, with motion numbers. A page needs a draft: run `dev` first | `--moment 8.4` |
| `--moment <s> --onion` | One blended image of the path of the move | `--moment 8.4 --onion` |
| `--moment <s> --velocity` | A speed graph for each element | `--moment 8.4 --velocity` |
| `--at <s> --box x,y,w,h` | A region enlarged with no smoothing. `--auto` finds the densest edge | `--at 2.4 --auto` |
| `--looks` | The frame under every named lens look, one grid per second | `--looks --at 4.5,9` |
| `--board` | An HTML board with a card per world | `--board` |
| `--directions` | The directions board: options A, B and C side by side | `--directions` |
| `--vs <mp4>` | The reference on the left, your film on the right, at the same seconds | `--vs ref.mp4 --at 2.5,3` |

A flag outside its mode exits with a one-line error. The old verbs `still`, `frames`, `sheet`, `strip`, `zoom` and `storyboard` still run. Each prints the `frame` command it became.

| Flag | What it does | Default | Example |
|---|---|---|---|
| `--size <WxH>` | With `--at <s>`: the PNG size. A page only. The ratio must match the aspect of the page, or the verb refuses | the aspect at 1920 on the long edge | `--size 1200x630` |
| `--aspect <W:H>` | With `--at`: set the aspect | the page meta, else 16:9 | `--aspect 1200:630` |
| `--param <key=value>` | With `--at`: pass an option to the page | none | `--param look=riso` |
| `--sheet` | With one `--at` second: write a sheet of one tile | off | `--at 3 --sheet` |
| `--labels`, `--cols <n>`, `--from <s>` | With a sheet: the labels, the columns, the first second | none | `--cols 3` |
| `--full` | With `--world`: full-size stills as `out/<name>-frames/<id>-full.png`. No sheet and no `frames.html` | off | `--world s3 --full` |
| `--sharp` | With `--world`: also shoot a full-size still per world (about 5 s more), so a click in `frames.html` opens it sharp | off | `--sharp` |
| `--span <s>` | With `--moment` or `--cuts`: seconds of film in the grid, the onion or the velocity window | 1 (`--onion` 0.3) | `--span 0.6` |
| `--fps <n>` | With `--moment`: frames per second of film in the grid. A grid holds 9 frames | 8 | `--fps 15` |
| `--n <n>` | With `--onion`: frames blended | 5 | `--n 6` |
| `--sel <css>`, `--ids <a,b>` | With `--velocity`: the elements to graph. A canvas painted in `window.seek` has no element, so pass `--sel` | the 4 elements that move most | `--sel .hero` |
| `--only <look,look>` | With `--looks`: the look names | all | `--only anamorphic,crt` |
| `--scale <n>`, `--at-b <s>` | With `--box`: the enlargement, and with `--vs` the second of the reference | none | `--at-b 2.6` |
| `--out <path>` | The output path. Not with `--world` | see [Files and outputs](/docs/files-and-outputs) | `--out out/f.png` |

```bash
bin/vawe frame films/card/page.html --at 0 --aspect 1200:630 --size 1200x630
bin/vawe frame films/my-film/page.html --moment 2.75 --velocity
```

## ship

The <Term id="final">final</Term>: 60 fps, <Term id="motion-blur">motion blur</Term>, audio mixed, then a final check and a fresh judge. It runs in the background. The verb refuses until a fresh review of the page exists and you have given two OKs: the plan, then the full draft. See [Ship](/docs/ship).

| Flag | What it does | Default | Example |
|---|---|---|---|
| `--aspect <W:H\|all>` | Set the aspect, or `all` for one file per aspect | the page meta, else 16:9 | `--aspect all` |
| `--param <key=value>` | Pass an option to the page | none | `--param look=riso` |
| `--out <path>` | Output file. It does not combine with `--aspect all` | `out/<name>.mp4` | `--out out/b.mp4` |
| `--wait` | Block until the render ends. With `--status`: wait up to 3.5 minutes, one progress line per minute | off | `--wait` |
| `--status` | Print the progress or the result of a background render | off | `--status` |
| `--profile` | Print a cost table: frames, subframes, screenshots, capture and encode seconds, the 5 costliest seconds | off | `--profile` |

The argument is a page, or with `--status` a page or a job id. The default job is the newest one.

```bash
bin/vawe ship films/my-film/page.html --aspect all
bin/vawe ship --status --wait
```

A final also writes a small web copy beside the master, `<name>.web.mp4` (`harness/media/render-page.mjs:10`, `:988`).

## What the verbs fix

`bin/vawe` does not expose these values as flags. The renderer sets them.

| Value | Draft | Final | Source |
|---|---|---|---|
| Output size | half of the aspect size, at device scale 0.5 | the aspect size | `resolveFrame` |
| Frame rate | 30 | 60 | `render-page.mjs:1233` |
| Subframes of motion blur per frame | 1 | up to 32 | `render-page.mjs:1235` |
| Frame capture | JPEG, quality 92 | PNG | `frameFormat` |

The CSS viewport is always the full aspect size, so a draft lays out exactly like the final. The environment variable `VAWE_WORKERS` sets how many browser pages capture at once.
