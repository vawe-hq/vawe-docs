## Steps

<Steps>
<Step>

### Write the brief

```bash
bin/vawe new hello --request "a 5 s sting for a coffee brand"
```

</Step>
<Step>

### Render a draft

```bash
bin/vawe dev films/hello/page.html
```

You see `out/hello-draft.mp4` and a `next:` line.

</Step>
</Steps>

## Callout

<Callout kind="note">
A draft with `--from` and `--to` renders only those seconds, without sound.
</Callout>

<Callout kind="warning">
Never pipe `bin/vawe` into `head`, `tail` or `grep`. The pipe hides the exit code.
</Callout>

<Callout kind="rule">
Time is the seek, never the clock. Every frame must come from `t` alone.
</Callout>

## Term

A <Term id="world">world</Term> holds one <Term id="beat">beat</Term>. The <Term id="virtual-clock">virtual clock</Term> makes timers follow the seek.
